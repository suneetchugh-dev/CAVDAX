# ADR-001: Adopt TokenAuth v1 for Payment Gateway

## Context
Our payment processing microservices require a lightweight token-based authentication mechanism for internal service-to-service communication.

## Decision
All payment checkout endpoints (`/api/v1/checkout/*`) MUST use **TokenAuth v1**.
The shared secret key must be verified using the `TokenAuth.v1.verify()` protocol.

## Consequences
- Fast header-based authentication.
- All coding agents and engineers must scaffold new payment routes using `TokenAuth.v1`.
