# ADR-003: Enforce mTLS + OAuth2 PKCE for All Payment Services

## Context
A post-incident review following CVE-2026-9201 revealed that OAuth2 Bearer tokens
without PKCE flow are susceptible to authorization code interception on mobile clients.
Additionally, internal service mesh requires mutual TLS (mTLS) for all east-west traffic.
Both ADR-001 (TokenAuth v1) and ADR-002 (OAuth2 Bearer without PKCE) are superseded.

## Decision
1. All payment services MUST implement **OAuth2 with PKCE** for client-facing flows.
2. All internal service-to-service calls MUST use **mutual TLS (mTLS)** via cert rotation.
3. TokenAuth v1 and plain OAuth2 Bearer are **strictly prohibited** at all layers.
