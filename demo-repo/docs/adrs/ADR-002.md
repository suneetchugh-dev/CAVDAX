# ADR-002: Mandatory Migration to OAuth2; TokenAuth v1 Decommissioned

## Context
A critical cryptographic flaw (CVE-2026-8941) was identified in TokenAuth v1, allowing replay attacks across internal payment proxies. ADR-001 is immediately revoked and superseded.

## Decision
1. **TokenAuth v1 is strictly deprecated and prohibited** across all services.
2. All payment and checkout endpoints (`/api/v2/checkout/*`) MUST exclusively authenticate using **OAuth2 Bearer Tokens (JWT with RS256 signatures)**.
3. Any autonomous coding agent or CI pipeline attempting to scaffold endpoints with `TokenAuth.v1` must be blocked immediately.

## Consequences
- Immediate invalidation of all historical architecture decisions dependent on TokenAuth v1 (including `DEC-102`).
- Requires revalidation to `DEC-103` (OAuth2 Implementation) before any code generation is permitted.
